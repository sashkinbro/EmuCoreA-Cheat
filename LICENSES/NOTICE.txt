The current generated PSP cheat data is derived from the Sony - PlayStation
Portable subset of libretro-database at commit
740ebdf03247073658ccea45ddedfd57ea9d2974:
https://github.com/libretro/libretro-database

The source repository provides a CC-BY-SA-4.0 license. The source README
states that cheat files are collected from web sources and user contributions,
so this catalog preserves upstream and original-author attribution and does
not relicense individual code authors' rights.

The former CWCheat Database Plus source is retained only as link-only
provenance in sources.json because its cheat data has no explicit
redistribution license in the pinned repository. No files derived from it are
included in the current manifest or release archives.
